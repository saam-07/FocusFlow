# 🚀 FocusFlow

FocusFlow is a productivity web app built around a simple question:

**"What should I do right now?"**

There are plenty of apps that let us write down tasks, set deadlines, and organize our work. The problem starts when the list becomes overwhelming. When you're tired, stressed, or short on time, deciding where to begin can be harder than doing the work itself.

FocusFlow was created to help with that decision.

Instead of simply storing tasks, FocusFlow looks at your available time, current energy level, task importance, and deadlines to recommend the best task to work on next.

---

## ✨ Features

### 📋 Task Management

* Add tasks with:

  * Task name
  * Importance level
  * Estimated time required
  * Deadline
* Delete tasks when completed
* Automatically saves tasks using Local Storage

### ⚡ Daily Context

FocusFlow takes your day into account.

You can enter:

* Class hours
* Sleep hours
* Current energy level

The app then calculates your available free time.

### 🧠 Smart Recommendations

Rather than showing a long list of tasks, FocusFlow suggests what you should focus on based on:

* Importance
* Deadline urgency
* Available time
* Energy level

The goal is to reduce decision fatigue and help you start working faster.

### 🔥 Built-in Pomodoro Timer

Once a task is recommended, you can jump straight into a focus session using the integrated Pomodoro timer.

---

## 🎯 Why I Built This

As a student, I often found myself in a situation where I knew everything that needed to be done but couldn't decide what to start with.

Some tasks were important but required a lot of energy.
Some were quick wins.
Others had deadlines approaching.

Most productivity apps helped me organize my work, but very few helped me decide what to do when I felt overwhelmed.

FocusFlow is my attempt to solve that problem.

## 🚀 How It Works

1. Add your tasks.
2. Enter your class hours and sleep hours.
3. Select your current energy level.
4. Generate a recommendation.
5. Start a Pomodoro session and begin working.
